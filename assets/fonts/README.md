# 元デザインのフォント

添付デザインと同じ Zen Maru Gothic（見出し：500/700/900）および Noto Sans JP（本文：可変ウェイト）をローカル配信します。外部Google Fontsへの通信は不要です。

出典：Google Fonts公式リポジトリ（2026年11月13日取得）

- https://github.com/google/fonts/tree/main/ofl/zenmarugothic
- https://github.com/google/fonts/tree/main/ofl/notosansjp

公式TTFからWOFF2へ変換。文字のサブセット削減は行っていません。各ファイルの文字マッピングが変換前と同一であることを確認しています。
ライセンスは同梱の `zenmarugothic-OFL.txt` と `notosansjp-OFL.txt` を参照してください。
