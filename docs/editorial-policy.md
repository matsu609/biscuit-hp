# ビスケット：制作・掲載方針

最終更新：2026年11月17日（日本時間）。ユーザーが林店長からのフィードバックを受け、この方針で進めること、後の指示と食い違う場合は指摘することを明示的に依頼しました。過去のデザイン案・生成画像の利用指示・人物紹介案より、この最新方針を優先します。

## 写真

- 店内・ホテルの設備を紹介する写真には、ビスケットの実際の店内・客室の写真を使用します。特にホテルは利用判断に直結するため、生成画像や他施設の写真で代用しません。
- 写真が未提供の場所は撮影予定・写真準備中の枠を残します。実在する人物・設備に見せるための画像を勝手に生成しません。
- 2026年11月17日、ユーザーの確認用デプロイ指示に基づき、サービスカードのAI画像3枚を提供された実写に差し替えました。生成画像ファイルも配信対象から削除しました。対応表はservice-images.jsonです。
- 掲載する写真と文章は、会長の最終確認を受けます。

## お店・スタッフの紹介

- お店のコンセプトや、オーナーがお店を開いた経緯は、会長も交えた聞き取りをもとに作成します。未確認の理念や創業ストーリーを創作しません。
- 紹介の中心は、実際にトリミングを担当する若いトリマーの皆さんです。トリマーを目指したきっかけ、飼っている犬、得意な犬種・スタイルなど、人物と技術が伝わる内容を聞き取ります。
- 林さん個人の経歴や医療知識を集客の中心として強調しません。店長としてチームの育成・運営を支える立場での紹介を基本とし、役割の具体的な表現はご本人・会長と相談します。
- 「林さん監修」「監修責任者」など、確認・承認の責任を引き受けたと受け取られる肩書きを未確認で付けません。
- 林さんは現在、新規の指名を受け付けていないと伺っています。林さんへの新規指名を促す表現は使いません。
- 法定の第一種動物取扱業者標識に載せる「動物取扱責任者」と、集客用のスタッフ紹介は区別します。マーケティング上の方針変更を理由に法定標識を勝手に削除しません。
- 現在のスタッフ紹介には林さん中心の旧案・ヒアリング項目が残っています。今後、上記方針に沿って修正する対象です。今回の記録作業では書き換えていません。

## 確認用ページと正式公開

- https://biscuit-hp.pages.dev/ は確認用のリニューアル版です。mainへのpushでCloudflare Pagesが自動更新されます。確認用ページへの反映と、正式公開・既存サイトからの移行を区別します。
- 正式公開・既存サイトからの移行は、写真と内容を整え、会長の最終確認を受けた後に進めます。独自ドメイン切替、DNS変更、正式公開のためのnoindex解除などを、通常の修正指示だけで進めません。
- ユーザーの「毎回確認なしでデプロイしてよい」という既存の指示は、確認用ページへの通常の修正反映に適用します。会長の最終確認を省略する根拠にはしません。

## ギャラリーと今後の指示

- 現在掲載中の2枚はココちゃん・ルイくんのトイ・プードルとの連絡を受けています。どの写真がどちらの名前かは未確認のため、勝手に対応付けません。
- ギャラリーのカット名は掲載しません。お客さまからカット名で指定されることが少ないというお店の意向を反映します。
- 今後、ユーザーがこの方針と食い違う指示をした場合は、変更や公開の前に該当する方針と相違点を簡潔に伝えます。忘れている可能性を踏まえて指摘し、黙って上書きしません。ユーザーが方針変更を明確に決めた場合は、この文書も更新します。
